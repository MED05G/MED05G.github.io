# Mohamed El Fellahi — Personal website

Live site: https://med05g.github.io/

A static personal website with a profile, selected research projects, and a web CV.
Built with HTML, CSS, and JavaScript; no build step is required.

## Local preview

Run `python3 -m http.server 4173` from this folder, then open
http://127.0.0.1:4173/.

## Publishing

GitHub Pages publishes the root of the `main` branch. Commit and push website
changes to update the live site. The `.nojekyll` file preserves plain static
publishing.

The previous design and the original application-specific PDF remain local.
The public CV is `cv.html` and includes a print/save-as-PDF option.
